# Three-minute demo script

**0:00–0:20 — Problem.** A distributor knows one supplier lot is recalled, but two container mappings are incomplete. The synthetic fixture preserves the resulting uncertainty.

**0:20–0:45 — Initial scope.** Show four possible-inclusion shipments and two shipments excluded under assumptions. Point to the visible safety notice and the 125 feasible histories.

**0:45–1:15 — Next evidence.** Open the ranked evidence queue. Explain that failed retrieval is included, so guaranteed benefit can be zero and the successful-outcome value is labelled conditional.

**1:15–1:45 — Human review.** Select the dispatch manifest, show its proposed fields and save the proposal. Confirm that the incident remains at version 1. Enter the reviewer and accept.

**1:45–2:10 — Decision diff.** Show version 2 and the manifest-linked change from possible to confirmed inclusion. Mention remaining ambiguity. If time permits, submit an impossible allocation to demonstrate conflict becoming unresolved.

**2:10–2:40 — Exasol and correctness.** Show the real schema/candidate smoke output and query timing after the team deployment has been verified. Show the independent bounds and adversarial test result. Do not claim this step before the live run exists.

**2:40–3:00 — Boundary.** RecallNext selects evidence; a qualified person decides physical action. State the small supported model and the next pilot-validation step.
